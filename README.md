# 한결 학원 평가 도우미 (Agent 기반 자동 채점 · 성적 분석 웹 서비스)

| 항목 | 내용 |
|---|---|
| 학번 | 202235030 |
| 이름 | 김한결 |
| 배포 URL | https://academy-grader-bluvxccabmptf23phqtba9.streamlit.app/ |

## 프로젝트 소개
영어 학원 원장님이 **문제지 PDF, OMR 인식 결과, 정답지 PDF**를 올리면 자동으로 채점하고, 결과를 엑셀로 추출하며,
채점 결과에 대해 자연어로 질문하면 답하거나 많이 틀린 문항과 유사한 문제를 만들어 주는 에이전트 웹 서비스입니다.

## 주요 기능
| 요구사항 | 구현 내용 |
|---|---|
| 1. 웹 페이지 구현 및 배포 | Streamlit 멀티페이지 — 페이지 1: 랜딩 / 페이지 2: 데이터 업로드 · 분석 · 채팅. Streamlit Community Cloud 배포 |
| 2. 자동 채점 | 사이드바의 문제지 · OMR · 정답지 칸에 각각 드래그 앤 드롭 → 올리는 즉시 내용 검증(문항 수·학생 수 표시, 칸을 잘못 고르면 안내) → **정답 PDF에서 문항 번호·정답·배점을 추출**해 채점 (정답 하드코딩 없음). 3개가 모두 있어야 분석 시작 가능, 채점 완료 후 엑셀 추출 버튼과 채팅 활성화. 업로드 파일이 바뀌거나 빠지면 이전 결과·엑셀·대화를 자동 초기화 |
| 3. 평가 결과 파일 추출 | 시트1: 전체 성적 개요(평균, 중앙값, 표준편차, 가장 많이 틀린 문항 TOP3) + 학생별 점수·문항별 O/X / 시트2: 문항별 정답률·선택지 분포 |
| 4. 채팅 기능 | 세션 안에서 대화 내역 기억 (DB 미사용), 일상 질문 응답 |
| 5. 채팅 세부 기능 | 통계 질의, 유사 문제 생성, 최저점 학생, 특정 학생 점수, 데이터 없는 질문 회피, 프롬프트 인젝션 방어 |

## 에이전트 구조
```
사용자 질문
  └─▶ 입력 보안 검사 (프롬프트 인젝션 패턴 차단)
        └─▶ LLM (OpenAI function calling)
              ├─ 필요한 조회 함수를 선택해 호출 → 파이썬이 미리 계산한 채점 결과 반환
              └─ 조회 결과를 근거로 한국어 답변 생성 (스트리밍)
                    └─▶ 출력 보안 검사 (내부 정보 유출 차단) ─▶ 화면 출력
```
- **숫자는 LLM이 계산하지 않습니다.** 평균·중앙값·순위 등은 pandas로 계산한 값을 그대로 전달해 정확도를 보장합니다.
- 채점 데이터에 없는 정보(출석, 수업 참여 등)는 "확인할 수 없다"고 답하도록 설계했습니다.
- 표준편차는 학원 전체 학생을 대상으로 하므로 **모집단 표준편차**를 사용합니다.
- 오답률이 같은 문항은 **문항 번호가 빠른 순**으로 정렬하고 동률 사실을 함께 안내합니다.
- **응답 시간**: 질문 하나 전체(LLM 호출 여러 번 + 도구 실행)에 18초 마감시간을 둡니다. LLM 호출은 백그라운드 스레드에서 하고 화면 쪽은 남은 시간만큼만 기다리므로, 서버 응답이 멈춰도 18초가 지나면 정해진 안내로 마무리합니다.
- **학생 조회**: `87번`, `900학생`, `1학년 87번 홍길동`, `S087` 등 번호 형식을 명시적으로 인식하고, 같은 번호·이름이 여러 명이거나 `87번과 88번`처럼 번호가 여러 개면 임의로 고르지 않고 후보를 보여줍니다.
- **보안**: 차단된 질문과 거절 답변은 다음 질문 때 모델에 다시 보내지 않으며, 답변은 내부 정보 포함 여부를 검사한 부분만 화면에 표시합니다.

## 데이터 검증
- OMR에 **문항 열 자체가 빠지면** 파일 오류로 보고 채점을 중단합니다. (정답지와 다른 시험이거나 파일이 잘린 경우)
- 문항 열은 있는데 **응답 칸이 비어 있거나 복수 마킹**이면 무응답으로 오답 처리하고 건수를 안내합니다.
- 정답지에 없는 문항에 OMR 응답이 있으면 채점을 중단하고, 빈 열이면 무시합니다.

## 개인정보 보호
- 업로드 파일·채점 결과·대화는 파일이나 DB로 저장하지 않고 **접속한 사용자 세션의 메모리(session_state)에만** 보관합니다. 서버 전체가 공유하는 캐시(`st.cache_data`)는 사용하지 않으며, 칸에서 파일을 지우면 읽어둔 내용도 즉시 삭제됩니다.
- OpenAI에는 질문에 필요한 **최소한의 조회 결과만** 전송합니다. 예를 들어 점수를 물으면 점수·순위만 보내고, 틀린 문항 상세는 오답 내역을 물었을 때만 별도로 조회합니다. 요청은 `store=False`로 보냅니다.
- 선택 기능: `APP_PASSWORD`를 설정하면 채점 페이지에 접속 비밀번호가 걸립니다. (과제 평가를 위해 기본값은 꺼져 있음)

## 기술 스택
Python · Streamlit · OpenAI API (gpt-5.4-mini, function calling) · pdfplumber · pandas · openpyxl

## 로컬 실행
```bash
pip install -r requirements.txt
cp .env.example .env   # .env 파일의 OPENAI_API_KEY= 뒤에 키 입력
streamlit run app.py
```
배포(Streamlit Cloud)에서는 `.env` 대신 앱 설정의 **Secrets** 칸에 `OPENAI_API_KEY = "sk-..."` 형식으로 입력합니다.

## 입력 파일 형식
- **정답지 PDF**: 문항 번호 / 정답(①~⑤) / 배점이 표로 된 정답표
- **문제지 PDF**: 2단 편집 시험지 (유사 문제 생성 시 원문 참고용)
- **OMR 결과**: 엑셀(.xlsx) 또는 CSV — `학생명, Q01, Q02, …` 형식 (응답은 1~5). `번호`와 `이름` 열이 따로 있으면 `87번 홍길동`처럼 합쳐서 인식
